Comparison Table

Comparison of Norman, GOMS, and KLM Models

Norman · GOMS · KLM

When to Use Which Model?

Use Norman when...

Analyzing user confusion, improving feedback, understanding cognitive load

Use GOMS when...

Breaking down complex tasks, comparing task procedures, training analysis

Use KLM when...

Predicting expert performance, comparing interface speed, optimizing frequent tasks

Conclusion

Each model provides a different perspective on interaction design. Norman helps understand how users think and where they get stuck. GOMS breaks down what users do into structured steps. KLM predicts how long expert users will take. Together, they help designers create more usable and efficient interfaces.
