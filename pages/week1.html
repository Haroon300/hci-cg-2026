Definition

Norman’s Action Cycle is a model that describes how people interact with systems. It breaks down interaction into stages — from thinking about a goal to checking if the goal was met.

Purpose

The model helps designers understand where users get stuck. By looking at each stage, we can make systems easier to use by giving better feedback and clearer controls.

Seven Stages of Action

  1. Forming the goal
  2. Forming the intention
  3. Specifying the action
  4. Executing the action
  5. Perceiving the system state
  6. Interpreting the state
  7. Evaluating the outcome

Gulfs of Interaction

⚡ Gulf of Execution

The gap between what a user wants to do and what the system lets them do. If controls are hidden or unclear, the gulf is wide.

🔍 Gulf of Evaluation

The gap between what the system shows and whether the user understands it. If feedback is confusing, the gulf is wide.

Example: Toggle Switch

Turning on a light with a switch:

  • Goal: Light on
  • Action: Flip switch
  • Feedback: Light glows
  • Evaluation: Room is lit

For Designers

Make controls visible. Give clear feedback. Bridge the gulfs so users don't have to guess.
