Definition

KLM (Keystroke Level Model) ek predictive model hai jo estimate karta hai ke ek expert user kitne time mein task complete karega. Ye low-level actions count karta hai jaise keystrokes aur mouse movements.

Purpose

KLM ka purpose hai different interface designs ko compare karna aur predict karna ke kaunsa design faster task execution allow karta hai. Designers isse use karke inefficient steps remove karte hain.

KLM Operators

K · Keystroke

keyboard button press (0.2–0.5 sec)

P · Pointing

mouse movement to target (1.1 sec)

H · Homing

hand movement between devices (0.4 sec)

M · Mental prep

thinking/decision time (1.2 sec)

R · Response

system reaction time (variable)

Example: Open a File

Task: Open a file from desktop

M
Decide to open file
1.2s
P
Move mouse to file
1.1s
K
Click file to select
0.2s
K
Press Enter (or double-click)
0.2s
R
System opens file
varies

Total time (without R): approx 2.7 seconds

Assumptions

Expert user error-free, no learning curve

No problem solving routine tasks only

Constant response system time is predictable

Use in Interface Design

Designers use KLM to optimize interaction — removing unnecessary steps, reducing hand movements, and placing controls strategically. Common in:

  • Menu layout optimization
  • Keyboard shortcut design
  • Form filling efficiency
