Definition

GOMS stands for Goals, Operators, Methods, and Selection Rules. It's a task analysis model that breaks down how users perform tasks into structured, predictable steps. Think of it as a recipe book for user actions.

Purpose

GOMS helps predict how long tasks will take and how efficient an interface is. Designers use it to compare different designs and find the fastest way for users to complete tasks.

Four Components

Goals

What the user wants to achieve — like "send an email" or "save a file"

Operators

Basic actions — clicking a mouse, pressing a key, moving hand to keyboard

Methods

Step-by-step sequences to reach a goal — e.g., File → Save As → type name

Selection Rules

Rules for choosing between methods — "if file is new, use Save As; if existing, use Save"

Example: Sending an Email

Goal: Send an email to a friend

  • Method:
  • 1. Open email app (click icon)
  • 2. Click "Compose" button
  • 3. Type friend's email address
  • 4. Type subject line
  • 5. Type message
  • 6. Click "Send" button

Each of these steps is an operator. Together they form a method.

GOMS in Practice

Advantages

  • Clear structure for task analysis
  • Helps spot unnecessary steps
  • Predicts expert performance time
  • Useful for comparing designs

Limitations

  • Assumes users are experts
  • Ignores learning curve
  • No emotional or social factors
  • Can be time-consuming to build

Quick Summary

GOMS is like a user's mental playbook. It breaks complex tasks into small pieces so designers can measure and improve efficiency. Best for expert users doing routine tasks.
