Identify and Fix Common HTML Mistakes

Semantic HTML and accessibility — This table shows common mistakes beginners make, along with their corrections. Each row presents incorrect code and the proper solution.

Common Semantic and Accessibility Errors with Corrections
Issue Wrong Code Correct Code
Navigation without list items
<nav> <a href="week1.html">Week1</a> <a href="week2.html">Week2</a> </nav>
<nav> <ul> <li><a href="week1.html">Week1</a></li> <li><a href="week2.html">Week2</a></li> </ul> </nav>
Label not associated with input
<label for="msg">Message</label> <textarea id="message"></textarea>
<label for="message">Message</label> <textarea id="message"></textarea>
Skipping heading levels
<h1>Models</h1> <h3>KLM</h3>
<h1>Models</h1> <h2>KLM</h2>
Image without alt text
<img src="diagram.png">
<img src="diagram.png" alt="Diagram of interaction model">
Table without caption
<table> <tr><td>KLM</td><td>Time</td></tr> </table>
<table> <caption>Comparison of models</caption> <thead>...</thead> </table>
Multiple aria-current attributes
<a aria-current="page">Home</a> <a aria-current="page">Week2</a>
<a>Home</a> <a aria-current="page">Week2</a>
Using div instead of nav
<div class="navigation"> <a href="week1.html">Week1</a> </div>
<nav> <a href="week1.html">Week1</a> </nav>
Non-descriptive link text
<a href="week1.html">Click here</a>
<a href="week1.html"> Week 1: Norman's Model </a>
Form without labels
<input type="text" placeholder="Name">
<label for="name">Name</label> <input id="name" type="text">
Missing lang attribute
<html> <head>...</head> </html>
<html lang="en"> <head>...</head> </html>

💡 Tip: Screen readers and assistive technologies require semantic HTML and proper attributes. Always include alt text for images, labels for form inputs, and maintain proper heading hierarchy.
